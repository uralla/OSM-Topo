## Packaging / BaseCamp / MapSource

### One-click installer for BaseCamp / MapSource

Для Mapsource-архива добавить Windows-скрипты установки и удаления карты.

Цель: пользователь не должен вручную искать системный каталог Garmin или разбираться в плохо очевидном механизме добавления карт в BaseCamp / MapSource.

Предлагаемое поведение установщика:

- найти корректный пользовательский каталог Garmin;
- скопировать туда комплект карты в отдельную папку продукта;
- при необходимости выполнить регистрацию карты для BaseCamp / MapSource;
- повторный запуск должен обновлять уже установленную карту, а не создавать дубликат;
- после успешной установки открыть папку назначения в Explorer;
- рядом положить отдельный uninstall-скрипт для корректного удаления карты.

Ожидаемые имена файлов в архиве:

- `install-map.cmd` (или CMD-обёртка над PowerShell);
- `uninstall-map.cmd`.

Статус: backlog, пока не реализовано.
