# Обзор стиля mkgmap `styles/uralla` (карты Garmin)

Дата: 2026-07
Статус: рецензия, изменения в файлы стиля НЕ вносились.

## 1. Итог

Стиль рабочий, основан на старом default-стиле mkgmap с большим числом кастомных
типов (0x1xxxx) и ручных корректировок. Ядро (дороги, water, landuse, DEM-гидроизогипсы)
спроектировано осмысленно, но в финальных правилах есть подтверждённые баги
(мёртвое правило AЗC, «гравийка» для асфальта, пустые имена), рискованные хаки
(маршрутизация по рекам через `taxi`, часы работы в `addr:postcode`) и значительный
объём мёртвого кода и жёстко закодированных списков имён, которые усложняют
обслуживание.

Приоритетные действия:
1. Починить 3 подтверждённых бага (см. §3.1).
2. Убрать/переделать хаки маршрутизации по рекам и «открытых часов» в почтовом индексе (§3.2).
3. Заменить жёсткие списки имён (реки, вершины, М-5) на пороговые/данные-ориентированные правила (§4.3).
4. Ввести README + build-скрипт, согласовать версии, сделать DEM-путь переносимым (§4.5).

- Активные типизированные правила `[0xNNNN` (≈557 всего):

## 3. Замечания

### 3.1 Подтверждённые баги

**Б1. Мёртвое правило АЗС.** `points:178` — `amenity=fuel [0x2f01 resolution 24]`
без `continue` перехватывает ВСЕ заправки; правила `points:180`
(`amenity=fuel & fuel:HGV_diesel=yes [0x2f16 …]`) и `points:182`
(`amenity=fuel & shop=convenience [0x2e06 …]`) **никогда не срабатывают**.
Типы 0x2f16 (дизель) и 0x2e06 (магазин при АЗС) отсутствуют на карте.
Исправление: добавить `continue` на строке 178 (и проверить, что 0x2f01
не нужен для всех случаев).

**Б2. «Гравийка» для асфальтированных дорог.** `lines:589` и `lines:594` —
в списке поверхностей для лейблов «(плохая гравийка)»/«(гравийка)»
включена `surface=paved`:
`…(surface=gravel|surface=compacted|surface=paved|surface=pebblestone|surface=fine_gravel)`.
Любая track/service/unclassified с `surface=paved` получает лейбл «гравийка» —
фактическая ошибка на карте (асфальт/брусчатка помечаются как гравий).
Исправление: убрать `surface=paved` из этих двух списков.

**Б3. Пустые имена без фолбэка.** `points`: `historic=memorial {name '${inscription}'}`
и `amenity=signpost {name '${label}'}` — если `inscription`/`label` отсутствуют,
имя становится пустым (POI без названия). Нужны цепочки фолбэков
(`'${inscription}' | 'памятник'` / `'${label}' | 'указатель'`).

**Б4. (подозрение) `add name='туннель'`** в финализере `lines`
(`highway=* & tunnel=yes`). `add name` — не стандартное действие mkgmap
(стандарт — `name '…'`), вероятно no-op; либо это осознанный хак — проверить.

### 3.2 Риски и хаки

**Р1. Маршрутизация по рекам через `taxi`.** `inc/water_lines:14` —
`{add access=no; add taxi=yes}` + комментарий в `lines:54-55`
`### taxi type is used for river routing` / `highway=* {add taxi=no}`.
Реки становятся проходимы для taxi-профиля (и любого профиля, где taxi
открыт по умолчанию). Это «грязный» канал: маршрутизатор может строить
путь по реке. Предлагаемый путь: отдельный класс дороги/реки с явным
`route`-разделением, либо `mkgmap:taxi` только там, где река действительно
проходима, с `access=no` для остальных.

**Р2. Часы работы в почтовом индексе.** `points:23` —
`opening_hours=* {set addr:postcode = '${addr:postcode} open ${opening_hours}' | 'open ${opening_hours}'}`.
Порча поля адреса: `addr:postcode` — это индекс, в него подмешивается текст.
Нарушает адресный индекс (`make-poi-index`, `housenumbers`) и поисковые
результаты. Предлагаемый путь: вынести в отдельное POI-поле/label
или использовать `addlabel`.

**Р3. `dem=/mnt/nod/dem`** в `uralla.args` — WSL/специфичный путь,
непереносим. `uralla-no-dem.args` содержит закомментированный
`# dem=/mnt/f/media-gps/dem/` — тоже среда-зависимый. Нужно:
переменная окружения или параметр сборки + README.

**Р4. Порogи `length()`, `area_size()`** привязаны к конкретной
геометрии тайла и к `simplify-lines=…` в args. При смене упрощения
или тайлинга поведение правил меняется молча.

### 3.3 Мёртвый код / чистка

- `relations`: правила для US/Asian сетей (`US:I`, `US:US`, `AsianHighway`, `TAH`) —
  нерелевантны для RU-карты.
- `inc/access_country`: BEL/NLD/ESP — нерелевантны.
- `inc/address`: правила NLD/DEU/AUT/POL/USA/… — нерелевантны для RU.
- `points`: 46 закомментированных правил (включая блок АЗС 186–190).
- `lines`: 33 закомментированных; блок подстановки имён отключён
  (комментарий с опечаткой «отлючено»).
- `polygons`: 23 закомментированных.
- `overlays` — пустой файл (0 B), можно удалить или заполнить.
- no-op: `name=* { name '${name}' }` в финализаторах (автоимя = текущее имя).
- `cycle-map` включён в обоих args (автомобильная/топокарта?) — проверить.
- `uralla-no-dem.args`: дублирование `process-destination`/`process-exits`
  (встречаются дважды), `max-jobs:4` (двоеточие) против `max-jobs=4`
  в основном args — синтаксис допустим, но не консистентен.

### 3.4 Несоответствия и гигиена

- **Версии**: `info` — `version=3.0`, файл `version` — `1`. Согласовать.
- **Английские default_name** в RU-стиле: `'Embassy'`, `'Services'`,
  `'Telephone'`, `'Toilets'` + 'Diesel/LPG' в `inc/name` — локализовать.
- **Порядок railway**: `railway=halt` res 19 vs `railway=station` res 21 —
  остановка видна дальше станции. Проверить, намеренно ли.
- **README/CHANGELOG/build-скрипт отсутствуют** в репозитории.
- `xuralla.typ` рядом с `uralla.typ` — экспериментальный артефакт,
  лучше перенести в `experiments/` или удалить.

## 4. Предложения по модернизации

### 4.1 Короткосрочные (быстрые фиксы)

1. `points:178` — добавить `continue` (Б1).
2. `lines:589,594` — убрать `surface=paved` из списков «гравийка» (Б2).
3. `points` — добавить фолбэки имён для `historic=memorial`, `amenity=signpost` (Б3).
4. `points:23` — убрать подмешивание `opening_hours` в `addr:postcode`;
   заменить на `addlabel` или отдельное POI-поле (Р2).
5. `info`/`version` — согласовать версию (4.1).
6. Удалить/заполнить `overlays`; зачистить закомментированные блоки;
   удалить no-op `name` правила.
7. Локализовать default_name: 'Embassy'→'Посольство', 'Services'→'Сервис',
   'Telephone'→'Телефон', 'Toilets'→'Туалет', 'Diesel/LPG'→'Дизель/Газ'.

### 4.2 Среднесрочные (структура)

1. **Реки и маршрутизация**: переделать Р1 — убрать `taxi=yes` с рек;
   при необходимости ввести отдельный `route`-класс для «проходимых» рек
   с явными условиями (`ford=yes`, `crossing=river` и т.п.).
2. **Данные вместо имён**: заменить жёсткие списки (56 имён) на:
   - вершины: `ele >= 4000` (или по регионам) вместо списка Эльбрус/Белуха/…;
   - реки: `width >= 50` / `intermittent!=yes` вместо Чусовая/Волга/…;
   - М-5: `ref ~ /^М-5$/` через `int_ref`/`nat_ref` (уже частично есть).
3. **Адреса**: вынести RU-логику (`inc/address`) в отдельный модуль
   с явными условиями по `addr:country=RUS` + level-маппинг;
   убрать нерелевантные страны (NLD/DEU/AUT/POL/USA/…).
4. **Пороги геометрии**: заменить часть `length()>N` на относительные
   условия (например, `length()/bbox-width` или `area_size` + класс дороги),
   чтобы правила не зависели от тайла.
5. **Дедупликация barrier/access**: собрать в один include, убрать
   тройное определение (points + inc/access + inc/compat_lines).

### 4.3 Долгосрочные (архитектура)

1. **Согласовать levels**: задокументировать привязку кастомных типов
   (0x1xxxx) к resolutions в README; при смене `levels` — авто-тест на
   наличие типов на каждом уровне.
2. **CI/тесты**: добавить build-скрипт + smoke-тест (mkgmap на маленьком
   OSM-фрагменте, проверка наличия ключевых типов 0x2f01, 0x2f16, 0x2e06
   и отсутствия ложных лейблов «гравийка» на асфальте).
3. **Версионирование**: единый источник версии (`info` = `version` = tag),
   CHANGELOG.md.
4. **Дем-данные**: параметризовать `dem=` через `--dem` в build-скрипте
   или env-var; задокументировать формат и разрешение.
5. **Артефакты**: перенести `*.typ`, `*.txt`, `xuralla.typ` в `build/` или
   `.gitignore`; оставить в репо только исходники стиля.
